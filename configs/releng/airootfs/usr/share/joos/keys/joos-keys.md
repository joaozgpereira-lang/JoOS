JoOS — Mapa de Atalhos (Super = tecla Windows)

  VERDE = lançamentos     ÂMBAR = janela     CIANO = navegação

  Super + Space            Menu de aplicativos
  Super + Alt + Space      Menu de controle (temas, brilho, sistema)
  Super + Return           Terminal (Alacritty)
  Super + Shift+Enter      Firefox
  Super + Shift + V        Histórico do clipboard

  Super + W                Fechar janela
  Super + F                Tela cheia
  Super + T                Flutuar / fixar janela
  Super + J                Alternar orientação da divisão
  Super + L                Alternar layout dwindle / master
  Super + C                Centralizar janela flutuante

  Super + cima/baixo       Focar vizinho (setas)
  Super + Shift setas      Mover janela no espaço
  Super + [  ]  ,  .       Redimensionar

  Super + 1..9             Ir para o espaço de trabalho
  Super + Shift+1..9       Enviar janela e seguir
  Super + Ctrl+setas       Espaços anterior/próximo

  Super + P                Captura de região (cola no clipboard)
  Super + Ctrl+P           Captura da tela inteira
  Print                    Captura rápida de região

  Super + K                Este mapa (abre de novo)
  Super + Esc              Menu do sistema (travar, reiniciar, desligar)
  Super + Ctrl+L           Travar sessão
  Super + Ctrl+Space       Próximo wallpaper
  Super + Ctrl+Shift+Space Próximo tema

  Super + Ctrl+Esc         Sair da sessão
  Volume / Brilho          Teclas Fn (XF86)

  Dica: o JoOS divide as janelas automaticamente conforme você abre
  (layout dwindle, como o Omarchy). Super + L alterna o layout.
